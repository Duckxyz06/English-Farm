# English Farm Visual Style Guide

## Core Style
- Pixel art 16-bit inspired
- Cozy farming simulation atmosphere
- Educational adventure feeling
- Warm and friendly visual language

## Color Direction
- Forest green
- Warm cream UI panels
- Wooden brown frames
- Sky blue backgrounds
- Seasonal natural colors

## Character Direction

### Momo
- Orange-white cat
- Green scarf with leaf/clover symbol
- Cute expressive face
- Friendly and curious personality

## UI Design
- Wooden sign headers
- Leaf decorations
- Cream information cards
- Pixel icons
- Clean grid layout

## World Design

Required locations:
- Main Farm
- Learning Area
- Central Town
- Forest
- Snow Mountain
- Beach
- Mystery Island

## Asset Requirements

Every future asset must match:
- Pixel art style
- Same Momo design
- Same UI language
- Same cozy English Farm identity

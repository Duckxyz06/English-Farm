# English Farm Learning System

## Core idea
Learning English is integrated into farming activities.

## Four skills

### Listening
- Listen to NPC instructions
- Choose correct action

### Speaking
- Read sentences aloud
- Pronunciation scoring

### Reading
- Match English words with farm objects
- Complete exploration tasks

### Writing
- Fill missing words
- Create simple sentences

## Progression

Level 1: Basic vocabulary

Level 2: Daily conversations

Level 3: Communication challenges

Rewards:
- Coin
- Gem
- Items
- Farm expansion

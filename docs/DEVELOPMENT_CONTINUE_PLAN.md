# English Farm - Continuous Development Plan

## Current rule
Continue development without stopping for confirmation until the first playable build is completed.

## Required quality gate before playable announcement
- Godot project opens successfully
- Main scene runs without errors
- Momo character appears
- Player movement works
- Camera follows player
- Farm environment is visible
- Visual assets match the approved English Farm style:
  - cozy pixel art
  - orange cat Momo with green scarf
  - wooden UI panels
  - cream backgrounds
  - natural farming environment

## Asset verification priority
Before integrating assets, compare against the provided references:
- Momo character identity
- Pixel art proportions
- UI style
- Farm atmosphere
- Item icon style
- Seasonal environment

## Milestones

### Prototype
- Core systems
- Data structures
- Design documents

### Playable Alpha
- Character movement
- Farm map
- Basic interaction

### Demo Build
- NPC dialogue
- English learning quest
- Reward loop
- Windows build

Do not announce playable status until the quality gate is passed.

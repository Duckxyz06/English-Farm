# English Farm - Playable Demo Plan v0.9

## Goal
Create the first playable Windows/Godot demo.

## Required systems

- Main scene
- Farm map
- Momo player controller
- Camera follow
- Basic interaction
- Inventory UI
- One NPC dialogue
- One English learning quest

## Current status

Completed:
- Core systems architecture
- Data structure
- Design documents
- Visual guidelines

In progress:
- Scene integration
- Pixel assets
- Playable flow

## Release condition

The project will be announced as PLAYABLE when:

1. Godot project opens successfully
2. Player can control Momo
3. A farm map is visible
4. Player can interact with NPC
5. Player can complete a learning quest
